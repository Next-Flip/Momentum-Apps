# [ESP32] Pwnpal

A full pwnagotchi on a Flipper + an ESP32 Wi-Fi board: social pwngrid peer, WPA/WPA2 handshake + PMKID capture, GPS wardrive, and hidden-SSID de-cloak. Capture/deauth ship off behind a consent gate.

The ESP32 runs a Marauder fork — one flash gives the full Marauder GUI plus the `pwnpal` command. The per-board ESP32 firmware and full docs live upstream on the GitHub release.

Upstream: https://github.com/mrq1911/pwnpal
